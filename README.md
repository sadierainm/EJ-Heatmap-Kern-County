# EJ Heatmap — Kern County

Starter structure for the Kern County environmental justice heatmap project.

## Project layout

- `src/` — application and analysis code
- `data/raw/` — source datasets (keep large or restricted data out of Git)
- `data/processed/` — cleaned and derived datasets
- `docs/` — project notes, methodology, and data-source documentation
- `tests/` — automated tests
